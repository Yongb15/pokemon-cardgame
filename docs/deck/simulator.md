# 내 컬렉션 덱 + 혼자 돌려 보기 — 설계

사용자 요청(2026-10-16): "직접 뽑은 카드로 덱을 만들고 그걸로 해 보고 싶다". 규칙대로 움직이는 대전은 하지 않는다. 카드 효과가 2만 장마다 다르고, 플레이 가능한 게임은 권리 위험이 크며, 실시간 대전은 지금 서버 구성과 맞지 않는다. 대신 아래 두 가지를 만든다.

1. **내 컬렉션으로 덱 만들기**: 카드팩에서 뽑은 카드로 덱을 채운다.
2. **혼자 돌려 보기(덱 시뮬레이터)**: 섞고, 첫 패를 뽑고, 프라이즈를 깔고, 드로우를 해 본다. 확률 통계도 함께 보여 준다.

**서버·DB 변경 없음.** 컬렉션은 기존 `GET /me/collection/summary`의 `owned`(cardId, count)를 쓰고, 계산은 모두 브라우저에서 한다.

## 1. 내 컬렉션으로 덱 만들기
- **카드 고르기**: 덱 편집의 카드 고르기에 출처 전환 **[전체 카드 | 내 컬렉션]**을 둔다. "내 컬렉션"은 로그인했을 때만 보인다.
  - 내 컬렉션 목록은 가진 카드(`owned`)를 카드 정보와 함께 보여 준다. 이름 검색과 종류(포켓몬·트레이너스·에너지) 필터는 브라우저에서 처리한다.
  - 카드마다 "보유 N장 · 덱 M장"을 표시한다.
  - 덱에 넣은 장수가 보유 장수에 닿으면 + 버튼을 막는다(이 화면에서만). 기존의 같은 이름 4장 규칙과 포맷 규칙은 그대로다.
- **덱 검사**: 로그인했고 컬렉션을 불러왔으면 정보 줄 하나를 더한다. 규칙 실패가 아니라 안내다.
  - 예: "내 컬렉션으로 채운 카드 52 / 60장 (모자란 카드 3종 8장)". 펼치면 모자란 카드 목록이 보인다.
  - **기본 에너지는 무제한으로 본다.** 실제 카드 게임에서도 기본 에너지는 따로 구하기 쉬워서, 컬렉션에 없어도 모자란 카드로 세지 않는다. 이 점을 문구로 밝힌다.
- 덱 데이터에 "컬렉션 전용" 같은 표시는 저장하지 않는다. 덱 형식과 계정 동기화는 그대로다.

## 2. 혼자 돌려 보기 (덱 시뮬레이터)
덱 편집 화면의 접히는 섹션 "혼자 돌려 보기"(덱 구성 아래). 덱이 60장일 때만 시작할 수 있다. 60장이 안 되면 "60장을 채우면 돌려 볼 수 있어요"를 보여 준다.

### 2a. 직접 해 보기
- **[섞고 시작]**
  1. 덱을 섞는다(Fisher–Yates, `crypto.getRandomValues`).
  2. 7장을 뽑는다.
  3. 기본 포켓몬이 없으면 패를 공개하고 되섞어 다시 뽑는다(**멀리건**, 횟수 표시).
  4. 이어서 프라이즈 6장을 뒷면으로 깐다.
- 화면 구성
  - **패**: 카드 그림을 가로로 스크롤한다.
  - **프라이즈 6장**: 뒷면으로 보이고, 눌러서 뒤집어 볼 수 있다(확인용).
  - **남은 덱 장수**와 멀리건 횟수.
- **[1장 뽑기]** → 패에 더한다. **[다시 섞기]** → 처음부터 다시 한다.
- 게임 규칙(기술 사용, 데미지, 진화)은 없다. 카드 배치와 드로우 연습만 한다.

### 2b. 확률 (몬테카를로)
같은 규칙으로 덱을 **20,000번** 섞어서 센다. 계산 시간이 짧지만 화면이 멈추지 않게 클릭했을 때 한 번만 계산한다.
- **첫 패에 기본 포켓몬이 있을 확률**(멀리건 없이 시작할 확률)과 평균 멀리건 횟수
- **카드 하나를 골라서**(덱의 카드 목록에서 선택)
  - 첫 패(7장)에 1장 이상 있을 확률
  - 첫 턴 드로우까지(8장), 두 번째 턴까지(9장) 볼 확률
  - **전부 프라이즈에 깔릴 확률**
- 숫자는 퍼센트 소수 한 자리로 표시하고 "2만 번 섞어 센 값이라 ±0.5%p 정도 차이가 날 수 있어요"를 밝힌다.
- 확인: 같은 계산을 초기하분포 공식과 비교하는 단위 시험(예: 기본 포켓몬 12장일 때 첫 패에 있을 확률 ≈ 81.5%)

## 3. 권리·안전
- 플레이 가능한 대전이 아니라 덱 점검 도구다(카드 효과·승패 없음). 카드 그림은 지금처럼 우리가 호스팅한 이미지를 쓴다.
- 서버로 보내는 것은 없다. 컬렉션 조회는 기존 API(본인 것, no-store)를 그대로 쓴다.
- 비로그인: 시뮬레이터는 그대로 쓸 수 있다(브라우저 덱). 컬렉션 기능만 숨긴다.

## 4. 시험
- 단위
  - 섞기 결과가 원래 덱과 같은 카드 구성인지
  - 멀리건 규칙(기본 포켓몬이 0장인 덱은 시작 불가로 안내)
  - 확률이 공식값과 ±1%p 안에 드는지
  - 컬렉션 부족 계산(기본 에너지 제외)
- qa
  - 컬렉션 전환·보유 표시·+ 막힘
  - 시뮬레이터 시작·드로우·프라이즈 뒤집기·다시 섞기
  - 모바일 패 스크롤, 다크 모드, CLS
  - 비로그인 상태
