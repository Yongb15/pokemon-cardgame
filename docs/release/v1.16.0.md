# v1.16.0 출시 체크리스트 (10팩 열기 · 중복 카드 교환 · 카드 만들기)

포함
- 10팩 한 번에 열기(10,000P): 울트라 레어 이상 1장 보장. 1~9팩에 없을 때만 10번째 팩의 레어 슬롯을 보장 확률로 뽑고, 확률은 공개한다
- 중복 카드 교환: 쓸 수 있는 1장은 남기고 경매·테스트 장은 제외, 등급별 10~3,000P, 하루 50,000P
- 카드 만들기: 교환 값의 10배, 하루 20장
- 약관 개정(시행일 2026-10-21)

검토: 설계·구현 Security 통과(X-1~X-9, I-x1, I-x2). qa 통과(L-1 수정 후 재확인).
