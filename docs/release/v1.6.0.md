1. 복구 지점: Neon 브랜치 `pre-v1.6.0`
2. 마이그레이션 0019(가격 알림)·0020(찜)
3. 확인(불리언): ALERTS·AUCTIONS(찜 포함)·NOTIFICATIONS 필요 권한 true, 초과 권한 false, app_rw·collector_rw account 접근 false, dev_marker 없음
