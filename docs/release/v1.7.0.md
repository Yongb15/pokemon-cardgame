## 2. 배포 순서 (중요)
옛 API는 비밀 묶음에 모르는 키가 있으면 시작을 거부하므로 **새 코드를 먼저**, 키는 그다음
1. `package.json` 1.7.0 → PR → CI → merge → 태그·Release → Deploy API(새 이미지, 키 없이: 가명은 비어 있음)
2. `api-secrets-prod` 새 버전 = 현재 버전 + `ADMIN_PSEUDONYM_KEY`(운영 전용 새 32바이트, 출력 금지) → `gcloud run services update api --update-secrets API_SECRETS=api-secrets-prod:<새 버전>` → 시작 로그 확인
3. 안정 확인 뒤 이전 비밀 버전 파기(사용자가 `!`로)
4. 운영자 계정을 admins에 소유자 SQL로(운영자가 실제 로그인한 계정)
