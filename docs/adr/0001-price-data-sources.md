# ADR 0001 — 카드 시세 데이터 출처

- 상태: 채택 (2026-10-08)
- 관련: M5 카드 시세

## 배경

카드 상세에 판본(영문·일본·한글)별 시세를 보여주고, 시세 추이를 그래프로 보여주려 한다. 조건은 **무료**, **합법적인 출처**, **공개 사이트에 표시 가능**.

## 검토한 선택지 (2026-10-08 조사)

| 출처 | 결과 |
|---|---|
| TCGdex API (`api.tcgdex.net/v2`) | 무료·키 없음. 카드별 `pricing`에 TCGplayer(USD)·Cardmarket(EUR) 시세. 일본판(`ja`)은 Cardmarket만. 등급 카드·가격 이력 없음, 버전이 섞인 시세가 있다고 알려짐. **일괄 조회 없음**(카드별 요청) |
| TCGdex 데이터 저장소 | MIT. 일본판 카드 12,781장(메가진화 포함), 한글판 239장(사실상 없음). 영문판과의 연결 정보 없음(Cardmarket 상품 id도 판본마다 다름) |
| TCGplayer / Cardmarket 공식 API | 신규 발급 중단 |
| pokemontcg.io | 신규 가입 중단, 2027-03-01 종료 |
| Scrydex, PokemonPriceTracker, PriceCharting | 유료(등급·이력은 월 $99 등) 또는 상업 이용 조건 불분명 |
| 크림·번개장터·당근 | 공개 API 없음. 번개장터 약관은 크롤링 금지 |
| 환율: Frankfurter / 한국수출입은행 | 둘 다 무료. Frankfurter는 키 없음·상업 이용 가능 |

## 결정

1. **영문판·일본판 시세는 TCGdex**에서 받아 **우리 DB에 매일 쌓는다**. 출처에 이력이 없으므로 이력은 우리가 만든다.
2. **한글판 카드 목록은 만들지 않는다.** 한글판은 일본판과 구성이 같으므로 "카드의 한글판"으로 다루고, 시세는 우리 경매 낙찰가(M7)와 사용자 제보(M6 이후)로 쌓는다. 그 전까지는 크림·번개장터 **검색 링크**만 제공한다(데이터 수집 없음).
3. 일본판은 TCGdex `ja` 데이터를 고정 커밋으로 가져와 **영문판 카드와의 연결표를 직접 만든다**(도감 번호·HP·기술 대미지·일러스트레이터·희귀도로 자동 대조 → 애매한 건 qa 검수). 영문판과 일본판의 Cardmarket 상품 id는 서로 달라 연결에 쓸 수 없다(2026-10-08 확인).
4. 환율은 **Frankfurter**를 하루 한 번 저장해 쓰고, 화면에는 원화와 원래 통화를 함께 표시한다.
5. 등급 카드(PSA 등) 시세는 이번 범위에서 제외한다(유료).
6. 모든 시세에 **출처·기준 시각·"참고용"**을 표시한다.

## 결과

- 비용 0원, 외부 키 없음.
- 갱신량 제한: 일괄 조회가 없어 하루에 받을 카드를 정한다(스탠다드 + 최근 조회 카드, 나머지는 상세 조회 시 하루 지난 것만). → [시세 설계](../price/design.md)
- TCGdex 시세의 버전 오류는 출처 표시와 "참고용"으로 알리고, 명백한 이상치는 저장 단계에서 거른다.
